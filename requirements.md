# Security Requirements — Identity, Access and Audit

## SR-01: MFA (TOTP) for all AEC staff and delegate accounts
- **Priority:** High
- **Complexity:** Medium
- **Description:** As an AEC staff member or state Commissioner's delegate, I must enter a time-based one-time password (TOTP, RFC 6238) in addition to my password before a session is issued, so that a phished or stolen password alone cannot give an attacker access to enrolment, candidate or result functions.
